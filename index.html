Project Overview

The Challenge

Unplanned equipment downtime is a major cost for industrial companies. The goal is to minimize this by proactively identifying machines at risk of failure.

The Solution

This project implements a dual-pipeline system. A robust **PySpark pipeline** handles large-scale training to build a highly accurate model. For real-time interaction, a **lightweight scikit-learn model** is deployed in an interactive Streamlit web app, demonstrating a professional "train heavy, deploy light" workflow.

Key Achievements

  • ✓Achieved **~97% prediction accuracy** with the PySpark model.
  • ✓Successfully handled the entire data pipeline from ingestion to model training.
  • ✓Deployed a live, interactive dashboard for real-time predictions.
  • ✓Demonstrated a professional workflow for big data and web deployment.
